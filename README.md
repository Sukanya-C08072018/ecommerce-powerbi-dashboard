# 📊 E-Commerce Sales Analysis Dashboard (Power BI)

## 📌 Project Overview
This project is an interactive Power BI dashboard designed to analyze e-commerce sales performance. It provides insights into sales, profit, customer trends, and regional performance to support data-driven business decisions.

---

## 🎯 Objective
To analyze e-commerce sales data and convert raw data into meaningful insights using Power BI.

---

## 🛠️ Tools Used
- Power BI
- Microsoft Excel

---

## 📊 Key Insights
- Sales and profit analysis
- Top-performing product categories
- Region-wise performance
- Customer trend analysis

---

## 👩‍💻 My Role
- Data cleaning using Excel
- Data transformation and modeling
- Dashboard creation in Power BI
- Insight generation
